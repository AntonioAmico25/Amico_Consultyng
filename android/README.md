# AMICO Consultyng — Android

Cliente Android de homologação do Ecossistema AMICO CONSULTYNG.

- Aplicativo: `br.com.amicoconsultyng.app`
- Versão: `0.1.0-homolog`
- Android mínimo: 7.0 (API 24)
- Destino: Android 15 (API 35)
- Portal oficial: https://amico-consultyng.amicoconsultyng.chatgpt.site

## Segurança

- somente HTTPS;
- erros de certificado são bloqueados;
- navegação interna restrita ao domínio AMICO;
- links externos abrem no aplicativo apropriado;
- acesso direto ao sistema de arquivos permanece bloqueado;
- cookies de terceiros permanecem bloqueados;
- backup do aplicativo desativado.

Esta versão é destinada a testes e homologação. Não representa publicação definitiva na Google Play.
